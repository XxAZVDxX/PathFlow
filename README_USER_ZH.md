# PathFlow

[English](README_USER.md) | [繁體中文](README_USER_ZH.md)

PathFlow 是一款為失明及弱視人士設計的 iPhone 出行輔助 App，將周遭環境語音描述、步行導航和香港巴士資訊整合在一起。

## PathFlow 可以怎樣協助你

- **詢問前方環境：** 以語音詢問前方情況，App 會根據相機畫面提供描述。描述可能不完整或有誤。
- **步行導航：** 搜尋目的地、在地圖查看路線，並收聽導航指引。路線顯示於地圖介面，不會疊加在即時相機畫面上。
- **查詢香港巴士資訊：** 搜尋附近巴士站，查看可用路線和預計到站時間。資訊會受所在位置及交通資料供應情況影響。
- **選用 LiDAR 距離提示：** 配備 LiDAR 的相容 iPhone 可估算前方距離，並提供威脅等級、震動或語音提示。這些估算不代表路面一定安全或沒有障礙。
- **使用輔助功能：** 支援 VoiceOver、語音輸入和語音指引。

## 裝置需求

PathFlow 需要執行 iOS 18.2 或更新版本的 iPhone。LiDAR 距離提示只適用於配備 LiDAR 的相容 iPhone。使用相關功能時，需要允許 App 存取相機、麥克風和位置。

## 出行安全提醒

PathFlow 是輔助工具，不能取代白手杖、導盲犬、安全判斷或無障礙設施。AI 描述和距離估算可能有誤，亦可能漏掉危險。出行時請繼續使用平日依賴的輔具並留意周遭環境。
